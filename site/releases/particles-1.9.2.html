Plasma Packages

Particles 1.9.2

A bug fix for PlasmaEngine 0.11.2. Previous package: Particles 1.9.1.

  • Fix an editor crash after editing a Mesh particle type while the effect plays. Clearing the Mesh while a Material was set made the next frame draw a mesh through an invalid handle, which stopped the editor in the depth pass. Reconfiguring an effect now checks its mesh and material again, and mesh particles without a valid mesh draw nothing.

Update plasma.particles to 1.9.2 and restart the editor. Assets, templates and shaders are unchanged from 1.9.1.

All plugins build against the 0.11.2 SDK.

Compared with each package's latest previously approved registry release. These notes describe the published 0.11.1 artifacts; adding notes does not replace their blobs.

plasma.ai 1.4.0

Previous: 1.3.0

  • Navigation blockers gain a Carve mode; blocked polygons are highlighted and floor reach is shown.
  • Sector status views, a per-team threat map and squad orders, with the squad map showing the navmesh sectors, other squads and agents.
  • Utility AI decision, perception and EQS improvements, and updated AI asset editors.

plasma.amplitude 1.2.1

Previous: 1.2.0

  • Rebuilt for engine 0.11.1; no functional changes.

plasma.angelscript 1.2.1

Previous: 1.2.0

  • Uses the engine's shared script tools: problems, breakpoints, call stack and variables in the Scripts panel, live reload reports, tagged script fields and project checks.
  • Adds the plasma-script-debug VS Code extension: VS Code attaches to the editor's debug adapter for breakpoints, stepping and variables.
  • Opening a script from the editor opens it in VS Code at the right line; script paths are reported relative to the project.

plasma.audio 2.1.1

Previous: 2.1.0

  • Rebuilt for engine 0.11.1; no functional changes.

plasma.cameras 1.0.0

Previous: First registry release

  • First release of Gameplay Cameras: a camera director, camera views and modifiers, and multi-subject framing.
  • Takes over the third-person view, head bone and camera shake components from Game Components, with their names and saved data unchanged.

plasma.csharp 1.3.1

Previous: 1.3.0

  • Uses the engine's shared script tools: problems (including background builds), debugging, live reload reports, script fields and project checks.
  • C# script classes have their own asset type, and classes keep their type across an in-place reload.
  • Fixed project builds failing on the script documentation line of generated projects, and stale error counts after a successful build.

plasma.diversion 0.2.1

plasma.gamecomponents 2.0.0

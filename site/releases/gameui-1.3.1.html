Game UI 1.3.1

Text rendering fix for PlasmaEngine 0.11.0. Previous package: Game UI 1.3.0.

  • Fix soft or broken text throughout the editor when Game UI is installed. The package mounted an older text shader over the corrected shader included in the engine.
  • Restore pixel-footprint sampling of small glyph strokes instead of the older single-sample smoothing.
  • Native binaries and SDK components are unchanged. No engine rebuild is required.

Update plasma.gameui to 1.3.1 and restart the editor.

Verified with package-tool captures in the installed 0.11.0 editor, including Shatterfall weapon, sight and attachment documents.

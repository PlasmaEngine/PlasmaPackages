PlasmaEngine 0.12.1 package changelists

Compared with each package's latest previously approved registry release. These notes describe the published 0.12.1 artifacts; adding notes does not replace their blobs.

All packages in this release:

  • Built for PlasmaEngine 0.12.1, Windows x64 Development, ABI win64-msvc19-0.12.1-abi7-dev. Packages built for 0.12.0 do not load in 0.12.1.
  • Refreshed package SDK headers and import libraries from the release build; rebuild project C++ code against this engine and these package versions.
  • This release has Windows components only. Linux and macOS games stay on the 0.12.0 packages until those platforms are rebuilt.

plasma.water 2.0.0

Previous: 1.3.0

  • Needs engine 0.12.1: water adds its passes to render pipelines itself, so it shows with no pipeline edits, costs nothing without water, and a pass that fails no longer takes the frame down.
  • Joined rivers and lakes are one seamless mesh, and a river reaches the ocean through an apron; ocean rings share their seams.
  • Waves from real FFT cascades, with the detail a mesh cannot show added per pixel; foam stays behind its wave and river detail follows the flow.
  • The sun is shadowed on water, lakes reflect their shores, and shallow water keeps its surface.
  • Four more water looks: Tropical Lagoon, North Sea, Mountain Lake and Muddy River.
  • plWaterWorldModule::RaycastSurface finds where a ray crosses the water surface, from above or below, for gameplay hits.
  • Editing a river or lake spline no longer stalls the editor, large lakes mesh again, lakes that rivers join mesh in about half the time, and river mouths at the ocean no longer leave gaps.

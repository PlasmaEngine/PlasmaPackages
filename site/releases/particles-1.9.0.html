Plasma Packages

Particles 1.9.0

VFX artist requests for PlasmaEngine 0.11.1: per-axis size, rotation and facing, emissive maps, adjustable depth blending and working distortion. Previous package: Particles 1.8.1.

  • Per-axis size. Random Size and Size Curve have a Per Axis mode, and Set Attribute a Size Scale target. The drawn size is Size times the X/Y/Z multipliers: quads use X and Y, meshes X, Y and Z, trails and ribbons X as their width.
  • Rotation and facing. Set Attribute can write Rotation (degrees; Add in Update is degrees per second) and Facing. The new Custom Facing quad orientation faces the Facing direction every frame. The Sparks template now stretches along the velocity, and a new Spinning Embers template is in the graph's templates.
  • Emissive map. Quads, trails and ribbons have an Emissive Map with colour, intensity and an optional effect colour parameter, added on top of the lit colour so fire cores keep glowing in shadow. Set Attribute's Emissive target multiplies it per particle. Six-way effects that used the Texture slot as their emissive are moved to the emissive map when opened or loaded.
  • Depth blending. Soft Edge Distance and Camera Fade Distance are now set per render type; the defaults (0.1 m and 0.5 m) match earlier versions. The soft edge now also fades Blend Add particles, which used to keep a hard line on the floor.
  • Distortion. The Distortion Texture and Distortion Strength fields show again for the Distortion render mode. Distortion particles are drawn by their own pass after all transparent objects, so heat haze bends fire and smoke in front of it, and without a texture they bend like a lens.
  • The quad, trail and ribbon shaders now ship in the package and take the place of the engine's copies. GPU systems that use the new size, rotation or emissive targets, per-axis sizes or Custom Facing run on the CPU and say why.

Update plasma.particles to 1.9.0 and restart the editor. Existing effects keep their look; reopen six-way effects once so the emissive move is saved.

All plugins build against the 0.11.1 SDK and the changed shaders compile for DX12.

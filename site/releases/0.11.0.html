plasma.audio 2.1.0

Previous: First registry release

plasma.particles 1.8.0

Previous: 1.3.8

  • Reworked the effect graph for the engine UI: system context stacks show blocks in execution order, with expand/collapse, enable toggles, drag reordering and undoable inline value editing.
  • Added typed operator wires and a graph compiler that folds constants, evaluates per-frame inputs once per simulation step and compiles per-particle expressions into runtime programs.
  • Added Set Attribute blocks in Initialize and Update, custom particle attributes and Kill If blocks; graph programs can read particle streams and sample gradients and curves.
  • Added per-particle wiring for drag, gravity factor, attraction force, scene-force influence, size-curve scale and gradient tint.
  • Added GPU execution of supported graph programs, including supported Set Attribute and Kill If updates, with explicit lowering diagnostics for unsupported graphs or block ordering.
  • Expanded particle events with velocity, color and size payloads, inherited values for event-driven spawning, and multiple named collision/death events.
  • Added event relationship information in the graph, warnings for unmatched event listeners and information about delayed GPU event delivery.
  • Added a live value spy with sample count, minimum/average/maximum, histogram and particle tinting; supported GPU values are read back with a delay.
  • Added deterministic preview timeline scrubbing and single-frame stepping by restarting and resimulating with a fixed seed.
  • Added preview motion modes and reporting for blackboard entries missing from the preview world.
  • Added conversion of legacy 1.3 logic blocks into operator graphs and attribute/kill blocks, with conversion notices and diagnostics for expressions that cannot compile.
  • Expanded particle runtime tests and CPU/GPU program reference coverage.

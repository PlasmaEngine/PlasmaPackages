plasma.audio 2.1.2

Previous: 2.1.1

  • Switching the audio output device keeps sounds playing from the same position on the new device.
  • Banks with corrupt, truncated or missing files are rejected and reported as failed instead of crashing or appearing loaded.
  • A bank counts as ready only when every event, clip and nested event it needs has loaded.
  • Stopping a sound with an invalid voice stops it immediately.

plasma.cameras 1.0.1

Previous: 1.0.0

  • The top-down view's script function RotateStep is renamed RotateBySteps; update scripts and Visual Script nodes that call it.
  • Adds a user manual for the camera package.

plasma.jolt 1.2.2

Previous: 1.2.1

  • Contact messages are queued and delivered after the physics step, so gameplay code reacting to collisions can no longer crash or deadlock the solver.
  • Breakable slabs, ragdolls and queued impulses handle deleted components safely, and ragdoll impulses only reach bodies the ragdoll owns.
  • A capsule with zero cylinder height works as a sphere, and a rope with too few pieces for its fixed anchors reports an error.
  • Collision mesh and heightfield caching no longer evicts newer meshes or shares tiles between empty IDs, and raycast queries are no longer capped at 256 hits.

plasma.networking 1.3.2

Previous: 1.3.1

  • Kicking a client, disconnecting during event dispatch or stopping the session from a callback no longer uses freed connection data.
  • Connections that never finish the handshake are dropped after a configurable timeout (default 10 s).
  • RPCs and object writes are authorised against the exact target component and its owner; scene components without an owner no longer accept remote writes.
  • Incoming messages, spawns and variants are bounds-checked: packet and variant sizes are capped and unregistered prefab IDs are rejected.

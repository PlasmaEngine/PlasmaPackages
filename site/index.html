Plasma Packages

The package registry for PlasmaEngine plugins. This site serves one generated file; the editor reads it, resolves what a project needs, and fetches the rest by content hash.

What is served here

  • index.plPackageIndex
    Every approved package and version, with dependencies, engine bounds and component hashes. Regenerated whenever the catalogue changes.
  • index.plPackageIndex.sig
    Detached Ed25519 signature over the index.
  • registry.pub
    Public half of the signing key. The engine ships a copy and refuses an index that does not verify against it.

Where the packages themselves live

Not here. Artifacts are content-addressed blobs attached to releases in this repository, sharded by the first byte of their hash, so a download URL is computable from the hash alone with no lookup: 

https://github.com/PlasmaEngine/PlasmaPackages/releases/download/blobs-<hh>/<sha256>.plpkg

A package is split into components — editor binaries, runtime binaries per platform, assets, localization, artwork — so a client fetches only what its platform and role need.

Using it

Add this registry as a source in the editor's Plugin Manager, or by hand:

Source
{
	string %Name{"plasma-official"}
	string %Index{"https://plasmaengine.github.io/PlasmaPackages/index.plPackageIndex"}
}
